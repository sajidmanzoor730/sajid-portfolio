Helpdesk KPI Dashboard

A Python and Streamlit reporting workflow that loads published IT helpdesk summaries, validates the source data, and lets readers explore request types, contact channels, departments and survey summaries across fiscal years.

Open live dashboard ↗ View source on GitHub ↗ Official data source ↗
Data provenance matters. The live Streamlit app reads the official Montgomery County Government MCG HelpIT Tickets public dataset. It contains aggregated summary rows—not individual tickets. The repository also retains an older synthetic ticket exercise; its ticket-level KPI figures are kept separate below and are not presented as live public-data results.

01 / Data workflow

From published source to a usable report.

The app fetches the public CSV when its cache expires, normalizes the source columns, applies basic quality checks and exposes filters for fiscal year and report group.

STEP 01

Load source

Request the official MCG HelpIT CSV with a timeout and a descriptive user agent.

STEP 02

Normalize fields

Map publisher column names into fiscal year, report group, item, count and percentage.

STEP 03

Validate rows

Coerce numeric values, exclude invalid required fields and remove duplicate summary rows.

STEP 04

Explore results

Filter report sections and fiscal years, then inspect charts and the underlying rows.

02 / Dashboard capabilities

04 / Quality controls

Validation before visualization.

The Python loader records a compact audit report so the dashboard can disclose what it accepted or excluded.

Schema mapping

Normalize headers and identify required source columns. Fail visibly if the official schema changes.

Type checks

Convert fiscal year, counts and percentages to numeric values; reject rows missing required dimensions.

Duplicate handling

Remove duplicate summary rows using fiscal year, report group, item and count as the comparison key.

Failure behavior: if the public source cannot be downloaded or its required schema cannot be identified, the app shows an error. It does not silently switch to generated or synthetic data.
05 / KPI eligibility

Why some helpdesk KPIs are intentionally absent.

Use this interactive field check to see why aggregated public summaries cannot support the same calculations as a row-per-ticket service desk export.

Current public source: aggregated summaries

Select the fields available in a dataset to see which calculations become supportable.

  • Request and contact counts: supported by published summary rows.
  • MTTR, ticket-level SLA, repeat rate and average CSAT: not supported by this public source.

08 / Run locally

Reproduce the dashboard.

git clone https://github.com/sajidmanzoor730/helpdesk-kpi-dashboard.git
cd helpdesk-kpi-dashboard
pip install -r requirements.txt
streamlit run app.py

The app needs internet access to retrieve the official public CSV. The dashboard caches the loaded data for one hour.
