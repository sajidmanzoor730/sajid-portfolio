Helpdesk KPI Dashboard

A Python and Streamlit project that cleans a raw helpdesk ticket export, calculates the KPIs support teams track, and presents them in an interactive dashboard.

Data provenance: This project uses a synthetic practice dataset created for learning. It includes 20 intentional duplicate or null rows to practise data-quality cleanup. It does not contain employer or customer data, and the results are not real-world figures. The live dashboard runs on a free tier and can take about 30 seconds to wake up.

What This Project Shows

Data cleaning

Finding and removing duplicates and null rows with Pandas, and checking the result before calculating anything.

KPI definition

Turning raw ticket fields into SLA adherence, CSAT, repeat rate and a priority breakdown.

Priority analysis

Comparing breach rates across P1 to P4 to see where SLAs slip most often.

Clear reporting

Presenting the results in a Streamlit dashboard that a non-technical reader can follow.

Run It

pip install -r requirements.txt
python clean_tickets.py
streamlit run app.py

Stack: Python, Pandas, Streamlit, Matplotlib. Files: Helpdesk_Tickets_Dataset_1000.xlsx, clean_tickets.py, app.py, requirements.txt.
