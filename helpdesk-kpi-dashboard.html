Helpdesk Ticket KPI Dashboard

An end-to-end analytics project that takes a deliberately messy helpdesk export through cleaning, validation, SQL analysis and dashboard reporting.

Business question

How can a support team turn a messy ticket export into reliable operational KPIs that reveal SLA performance, customer satisfaction, repeat tickets and priority-level patterns?

Workflow

1. Source data.
Created a synthetic helpdesk export covering March–August 2026 with 5,100 rows, including deliberate duplicates and blank fields.
2. Data cleaning.
Used Python and Pandas to remove duplicate records, handle blank category/agent values and check date fields. The cleaned dataset contains 5,000 unique tickets.
3. SQL analysis.
Used SQL for deduplication with ROW_NUMBER, SLA-policy JOINs, monthly trend analysis with LAG, and agent ranking within teams using RANK.
4. KPI reporting.
Calculated SLA adherence, SLA breach rates, average CSAT and repeat-ticket rate, then presented the results through Streamlit and a Power BI report.

Key findings

  • SLA adherence: 94.3%, with 5.7% of tickets breaching SLA.
  • P1 SLA breach rate: 20.9%, compared with 2.8% for P4 in this synthetic dataset.
  • Average CSAT: 3.96/5.
  • Repeat-ticket rate: 11.0%.
  • Raw-data quality: 95.6% of rows were free from the duplicate/blank issues intentionally introduced for the exercise.
