02 / Investigation flow

From symptom to evidence.

Each stage is represented in the repository through a script, query, API collection or packet-filter reference.

STEP 01
⌁

Parse SIP logs

Extract SIP response codes and potential one-way-audio indicators from a log file.

STEP 02
⌘

Validate APIs

Test registration state, response time, call-quality fields and authentication responses.

STEP 03
▤

Analyse tickets

Use SQL to group issue types, calculate CSAT/SLA measures and inspect KB-linked deflection.

STEP 04
◉

Inspect packets

Apply SIP, RTP, RTCP and STUN display filters to narrow down network-side causes.
