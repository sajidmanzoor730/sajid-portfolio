Investigation Workflow

1. Read the logs

Parse log files and count error codes to see which errors are most frequent before digging into any single one.

2. Check the API

Run a health check against an endpoint to confirm it responds, how quickly, and with the expected fields.

3. Query the data

Use SQL to group errors by type and see how often each one occurs.

4. Hand off

Collect the results into a short evidence summary that an engineer can act on without repeating the checks.
