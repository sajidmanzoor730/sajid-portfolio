CRM Data Quality & Cleanup

A record-level cleanup workflow covering duplicates, missing fields, normalization, enrichment and follow-up, measured on the raw file before cleanup and the clean file after it.

Data note: This dashboard analyzes a synthetic CRM dataset covering January–September 2026. The raw file has 3,090 rows; merging 90 duplicates produced the 3,000-record clean file. Emails use the reserved .example domain, so it contains no real customer or employer data. It focuses on data quality, record completeness, duplicate detection, normalization and follow-up tracking.

SQL behind the findings

These queries reproduce the dashboard numbers outside the browser. The results below were produced by running these queries on the clean CSVs (SQLite). Reproduce them with python3 sql/run_sql.py.

crm duplicates in raw

-- Duplicate rows = a later record that repeats an earlier email OR company name
WITH ranked AS (
  SELECT Record_ID,
         ROW_NUMBER() OVER (PARTITION BY LOWER(TRIM(Email))
                            ORDER BY Record_ID) AS email_rank
  FROM crm_raw
  WHERE TRIM(Email) <> ''
)
SELECT (SELECT COUNT(*) FROM crm_raw)                       AS raw_rows,
       (SELECT COUNT(*) FROM crm)                           AS clean_rows,
       (SELECT COUNT(*) FROM crm_raw) - (SELECT COUNT(*) FROM crm) AS rows_removed,
       (SELECT COUNT(*) FROM ranked WHERE email_rank > 1)   AS repeated_emails_in_raw;

crm issue resolution

SELECT Issue_Type,
       COUNT(*)                                                       AS records,
       SUM(Action_Taken IN ('Merged','Standardized','Enriched'))       AS resolved,
       SUM(Review_Status <> 'Ready')                                   AS needs_follow_up,
       ROUND(100.0 * SUM(Action_Taken IN ('Merged','Standardized','Enriched')) / COUNT(*), 1) AS resolution_pct
FROM crm
WHERE Issue_Type <> 'None'
GROUP BY Issue_Type
ORDER BY records DESC;

crm quality by owner

SELECT Owner,
       COUNT(*)                                                          AS records,
       ROUND(100.0 * SUM(Issue_Type <> 'None') / COUNT(*), 1)            AS issue_rate_pct,
       ROUND(100.0 * SUM(Review_Status = 'Ready') / COUNT(*), 1)         AS ready_pct,
       ROUND(AVG(Completeness_Score), 1)                                 AS avg_completeness
FROM crm
GROUP BY Owner
ORDER BY ready_pct;
