Helpdesk KPI Dashboard — ServiceNow Structure

Analyzed 1000 unique helpdesk tickets (1020 rows) to track SLA breach, MTTR, CSAT and agent performance. Built interactive Power BI dashboard with DAX & SQL analysis.

Dataset: 1020 anonymized tickets (1000 unique) — ServiceNow structure (Priority P1-P4, SLA breach, MTTR, CSAT, Channel). Columns: Ticket_ID, Created_Date, Category, Resolution_Time_Hours, SLA_Breach_Flag. No employer or client production data. File: data/Helpdesk_Tickets_Dataset_1000.xlsx

Stack: Power BI, DAX, SQL (Joins, CTEs, Window Functions, Aggregations), Excel, KPI Design

Key Metrics: SLA Breach 8.8%, Avg MTTR 19.2 hrs, Avg CSAT 3.73, Avg First Response 42 mins

SQL Ready: SELECT Priority, AVG(Resolution_Time_Hours) FROM Tickets_Raw GROUP BY Priority | CTE for Monthly SLA | ROW_NUMBER() for Agent Ranking
