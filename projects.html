SMTP/IMAP Troubleshooting Lab

A zero-dependency toolkit that identifies whether an email failure comes from DNS, TCP, TLS, authentication or server policy. It includes protocol probes that act as a mail user agent (MUA) against mail transfer agents (MTA), a diagnosis engine that maps reply codes and TLS or socket errors to likely causes, and a fault-injecting mock server that reproduces nine failures.

PythonSMTP/IMAPTLSOAuth2GitHub Actions
  • SMTP + IMAP probes
  • Failure classification
  • OAuth2/XOAUTH2
  • 47 automated tests
  • Nine reproducible failure scenarios
Scope note: test accounts only, no customer data. Automated tests use local mock servers. Gmail and Microsoft 365 smoke tests are an opt-in workflow and are not presented as completed provider validation.
