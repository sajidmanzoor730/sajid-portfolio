Executive Operations Dashboard

An interactive dashboard for monitoring workload, priorities, deadlines, SLA performance, follow-ups and overdue work across operational teams.

Data note: This dashboard runs on the Executive Operations Dataset, a structured operational dataset of 6,000 records covering January–September 2026. The raw file (6,060 rows) was de-duplicated on Record_ID to produce the clean file used here. It contains no confidential employer or customer data.
