Investigation scope

Alert triage and endpoint review

The lab covers several common security alert categories and the evidence an analyst would review.

Endpoint

Malware and suspicious execution

Review malware detections and suspicious PowerShell activity, identify the affected device and entity, inspect alert context and record the investigation state.

Identity and access

Credential-access indicators

Use alert context and mapped techniques to understand suspicious credential-access behavior. A technique mapping is an investigation aid, not proof that an attack succeeded.

Network

Unusual network connections

Review unusual connection alerts alongside timestamps, device context, detection source and related entities before recommending escalation.

Email

Phishing alerts

Classify phishing-related alerts, assess severity and document the available evidence and response status in the practice dataset.

Microsoft Sentinel · KQL

Query patterns for investigation

The repository includes 5+ KQL examples for filtering, aggregation, severity analysis and entity-level review.

Example: high-severity alert counts

AlertInfo | where Timestamp > ago(30d) | where Severity == "High" | summarize AlertCount = count() by Category, DetectionSource | order by AlertCount desc
Validate table availability, column names, workspace permissions, join keys and time ranges in the target Microsoft Sentinel environment. The sample queries are not guaranteed to run unchanged in every tenant.
Investigation method

From alert to documented response

01 · TRIAGE

Prioritise

02 · INVESTIGATE

Gather context

Inspect affected devices, entities and related evidence.

03 · CORRELATE

Query and map

Use KQL templates and MITRE ATT&CK mapping to organise findings.

04 · DOCUMENT

Record outcome

Capture status, response action and escalation notes.
